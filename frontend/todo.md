# AEXTRECIBER - Asociación Extremeña de Ciberseguridad - Plan de Desarrollo

## Directrices de Diseño

### Referencias de Diseño (Inspiración Principal)
- **Kaspersky.com**: Diseño profesional en ciberseguridad
- **Norton.com**: Confianza y seguridad visual
- **Estilo**: Moderno Tecnológico + Seguridad Digital + Profesional Corporativo

### Paleta de Colores
- Primario: #0F172A (Azul Oscuro - seguridad y confianza)
- Secundario: #1E40AF (Azul Intenso - tecnología)
- Acento: #3B82F6 (Azul Brillante - innovación)
- Alerta: #EF4444 (Rojo - amenazas/alertas)
- Éxito: #10B981 (Verde - protección)
- Neutro: #F8FAFC (Gris Muy Claro - fondos)
- Texto: #1E293B (Gris Oscuro), #64748B (Gris Medio)

### Tipografía
- Heading1: Inter font-weight 700 (48px)
- Heading2: Inter font-weight 600 (36px)
- Heading3: Inter font-weight 600 (24px)
- Body/Normal: Inter font-weight 400 (16px)
- Body/Emphasis: Inter font-weight 600 (16px)
- Navigation: Inter font-weight 500 (16px)

### Estilos de Componentes Clave
- **Botones**: Fondo azul (#1E40AF), texto blanco, 8px redondeado, hover: brillo +10%
- **Tarjetas**: Fondo blanco, borde sutil, 12px redondeado, sombra suave
- **Iconos**: Shield, Lock, Users, Award para representar seguridad
